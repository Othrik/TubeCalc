Calculadora de preparación de disoluciones

Preparación de disoluciones / stocks: introduce «stock → concentración final» y obtienes el volumen de cada componente (V = C_{\text{final}} \times V_{\text{total}} \div C_{\text{stock}}). Admite × concentrados, % v/v, % p/v y pesada de polvos; deja vacía la concentración final y escribe la cantidad directamente para el modo manual. El disolvente completa solo; todo se guarda en este navegador.
