Analyse de séquence de protéines

Collez une séquence protéique (code à une lettre, en-tête FASTA accepté) pour obtenir la masse molaire, le pI théorique, le coefficient d’extinction \varepsilon_{280}, la courbe charge–pH et la composition en acides aminés.

Charge nette (pKa de Bjellqvist) selon le pH ; la ligne pointillée marque le pI théorique (charge nette = 0). Au-dessus de son pI la protéine est négative — échange anionique ; en dessous, positive — échange cationique. Survolez pour les valeurs.
Hydropathie moyenne par fenêtre glissante ; la ligne pointillée à 1,6 est une référence empirique de tendance transmembranaire (la fenêtre de 19 est la plus efficace). Les segments mieux notés tendent à se situer dans les cœurs hydrophobes / régions transmembranaires. Survolez pour les valeurs par résidu.
Target–disease–drug associations via Open Targets Platform (GraphQL). Principe : masse moléculaire = somme des masses des résidus + H2O ; ε280 estimé avec Trp 5500 / Tyr 1490 / cystine 125 ; pI d’après les pKa de Bjellqvist. Références : Gill SC, von Hippel PH. Anal Biochem. 1989;182(2):319-26 ; Bjellqvist B, et al. Electrophoresis. 1993;14(12):1223-31.
